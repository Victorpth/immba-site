# FJCU imMBA

A bilingual website for the MBA in International Management (imMBA) at the College of Management, Fu Jen Catholic University.

The site covers the same jobs as the program’s current pages: admissions for international and local students, tuition and scholarships, curriculum and graduation rules, faculty, the student guide, dual degrees, exchange, news, document downloads, search, and a contact form. The presentation is a quieter editorial layout in English and Traditional Chinese.

Application systems, brochures, and regulations still open from Fu Jen’s own sites. Confirm deadlines and fees with the imMBA office before applying.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) if you start the server with that port:

```bash
npx next dev --hostname 0.0.0.0 --port 4321
```

The home page follows the browser language: Chinese (`zh`) or English (`en`). Use the language switch in the header to change.
